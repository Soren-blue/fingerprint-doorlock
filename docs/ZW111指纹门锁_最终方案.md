# 指纹门锁完整方案·最终版（HLK-ZW111 + ESP32 + SG90）

> 顺序：买零件 → 接线 → 装软件 → 录指纹 → 上传开门程序 → 装门上 → 通电用
>
> **铁律：先在桌上把电子部分调通（手指一按舵机就转），再装门。**

本版相对初版的两处修正：

1. 指纹库改用 **HLK_fingerprint**（Adafruit 库不支持 ZW111 的 EF-01 协议）
2. 接线补上 **V_Touch** 引脚（ZW111 是 6 针，V_Touch 必须接 3V3）

## 配套文件

- [enroll_fingerprint.ino](../firmware/enroll_fingerprint/enroll_fingerprint.ino) — 录指纹程序
- [fingerprint_doorlock.ino](../firmware/fingerprint_doorlock/fingerprint_doorlock.ino) — 开门程序

## 第2步：接线（指纹6根 + 舵机3根）

### 指纹模块（6根，V_Touch 别漏）

| ZW111 引脚 | 接ESP32 | 说明 |
|---|---|---|
| V_Touch | **3V3** | 触摸供电，**必须接**，最容易漏 |
| VCC | **3V3** | 只吃3.3V，**绝对不能接5V** |
| GND | GND | |
| TX | D16 | 交叉：模块TX→板子RX |
| RX | D17 | 交叉 |
| TOUCH_OUT | D4 | 可选，程序用不到，不接也行 |

### 舵机（3根）

| 舵机线颜色 | 接ESP32 |
|---|---|
| 棕色/黑色 | GND |
| 红色 | 板子的 5V（有的板子写 VIN） |
| 橙色/黄色 | D13 |

### 供电与 3V3 分线（VCC 和 V_Touch 共用 3V3）

整套东西的电源就是一根 USB 线：一头插板子，另一头插 5V 电源。

| 供电方式 | 适合 | 说明 |
|---|---|---|
| 插座上的 5V/2A 充电头 | 长期 24 小时挂着 | 最稳，推荐 |
| 充电宝 | 临时 / 没插座时 | 电流很小时充电宝会自动断电，板子跟着重启 |

**VCC 和 V_Touch 都要接 3V3，两根线接同一个 3V3 点：** 用一根 **一母对二公** 杜邦线，母头插板子的 3V3，两个公头分别插指纹模块的 VCC 和 V_Touch。

> 也可以两根线叠插在同一个 3V3 引脚上（并联，不会烧），但针脚只有一个时容易插不稳，用"一母对二公"最稳。

其他两点：

- **GND 都要接**：舵机和指纹模块的地都接到板子的 GND
- 舵机红线接板子的 **5V / VIN**，**不要接 3V3**

### 通电自检

USB线插ESP32，另一头插充电头/充电宝。蓝灯亮、摸舵机有轻微震动（正常）。

**红线（舵机）插5V；指纹模块的 VCC 和 V_Touch 都插3V3，绝不能插5V。** 线色以商家实物为准，按丝印文字核对。

## 第3步：电脑装软件（一次性）

1. 下载安装 Arduino IDE（官网 arduino.cc）
2. **文件 → 首选项** → 附加开发板管理器网址，粘贴：
   `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json` → 确定
3. **工具 → 开发板 → 开发板管理器** → 搜索 `esp32` → 安装 **esp32 by Espressif Systems**（等它装完）
4. **工具 → 管理库** → 分别安装 **HLK_fingerprint**（作者 GavinnnTann）和 **ESP32Servo**

> 不要装 Adafruit Fingerprint Sensor Library——它面向 AS608/R307 那套协议，不兼容 ZW111（HLK_fingerprint 库作者实测确认）。

5. 插USB线 → **工具 → 开发板**选 **ESP32 Dev Module** → **工具 → 端口**选带USB的选项

> 端口没有选项 = USB线不能传数据，换线。

## 第4步：录指纹

最简单：装好库后打开 **文件 → 示例 → HLK_fingerprint → enroll**，上传，按串口提示操作。

也可以新建草稿，粘贴 [enroll_fingerprint.ino](../firmware/enroll_fingerprint/enroll_fingerprint.ino)：

```cpp
#include <HLK_fingerprint.h>

FingerprintModule fp(Serial1, 16, 17);   // 16=收(接模块TX)，17=发(接模块RX)

void setup() {
  Serial.begin(115200);
  if (!fp.begin()) {                     // 默认波特率57600，同时验证密码
    Serial.println("没连上！检查：VCC和V_Touch都接3V3、TX↔RX交叉");
    while (1) delay(1);
  }
  Serial.println("指纹模块连接成功！输入编号(1~100)回车，再按提示按两次手指");
}

void loop() {
  if (Serial.available()) {
    int id = Serial.parseInt();
    if (id < 1 || id > 100) { Serial.println("编号要在1~100之间"); return; }
    Serial.print("录入编号 "); Serial.println(id);
    int16_t r = fp.enrollFingerprint(id);   // 同一根手指按两次
    if (r >= 0) Serial.println("录入成功！编号 " + String(r));
    else Serial.println("录入失败，重新来");
  }
}
```

操作：输入框打 `1` 回车 → 按提示放手指 → 拿开 → 再按一次 → 显示"录入成功！编号 1"。

**同一根手指建议录两个编号**（右手食指录成1和2），识别率更高。给别人用就输新编号（3、4、5……）重复操作。

> 判断标准：串口监视器显示"录入成功！编号 1"。

## 第5步：上传开门程序

新建草稿，粘贴 [fingerprint_doorlock.ino](../firmware/fingerprint_doorlock/fingerprint_doorlock.ino)，上传：

```cpp
#include <HLK_fingerprint.h>
#include <ESP32Servo.h>

FingerprintModule fp(Serial1, 16, 17);
Servo myServo;

int servoPin = 13;
int openAngle = 110;   // 开锁角度，按门锁行程微调(110→120→130)
int idleAngle = 0;     // 待机角度

void setup() {
  Serial.begin(115200);
  pinMode(2, OUTPUT);              // 板载LED
  myServo.attach(servoPin);
  myServo.write(idleAngle);
  if (fp.begin()) Serial.println("指纹模块OK");
  else Serial.println("指纹模块没连上！");
}

void loop() {
  uint16_t score;
  int16_t id = fp.matchFingerprint(score);   // >=0=匹配；-1=指纹不对；-2=没人按
  if (id >= 0) {
    Serial.print("匹配成功 ID="); Serial.println(id);
    digitalWrite(2, HIGH);
    myServo.write(openAngle);
    delay(2000);
    myServo.write(idleAngle);
    digitalWrite(2, LOW);
    delay(1000);
  } else if (id == -1) {                     // 只有指纹不对才闪灯
    Serial.println("指纹不匹配");
    for (int i = 0; i < 3; i++) {
      digitalWrite(2, HIGH);
      delay(100);
      digitalWrite(2, LOW);
      delay(100);
    }
  }
  // id == -2：没人按手指，保持待机不闪灯
  delay(100);
}
```

**成功标准：手指按模块 → 蓝灯亮、舵机转过去、2秒后转回来。** 电子部分完成，拔掉电脑。

## 第6步：装到门上

原理：舵机转 → 线拉锁钮开锁；舵机松 → 锁钮回到上锁位（本方案不含机械回位装置，上锁依靠门锁自身回位）。

1. 用手拨锁钮，确认开锁方向和行程
2. 3M胶把舵机粘在锁钮旁边（拉线方向那侧，距5~10cm），按1分钟，扎带加固
3. 舵机装圆盘臂（用外孔，拉线行程最大）
4. 用缝衣针穿线：线一头绑在舵机臂外孔，另一头用针穿过锁钮的孔打结；锁钮没孔就用针把线绕过锁钮勒紧再打结（针尖朝外，别扎手）
5. 调线长：舵机在0度时线**刚好绷直、不拉动锁钮**
6. 指纹模块用3M胶贴在门板顺手位置（传感器面朝外），线用透明胶带沿门边贴牢

**成功标准：手指按10次都能开锁；手指拨锁钮松手能自动复位。**

## 第7步：日常使用

- **供电**：手机充电头（5V/2A）+ 数据线，插插座 24 小时常开最稳；充电宝只在没插座时临时用（小电流会自动断电）。
- **识别失败**：传感器表面擦干净；同一根手指多录几个编号（录成2、3）。
- **逃生底线**：拔掉电后手指必须能轻松拨开锁钮。
- **装之前问一句宿管/家长，确认不影响消防逃生。**

## 卡住时查这5条

1. **上传失败** → USB线不能传数据，换线；或按着板上BOOT键再点上传
2. **显示"没连上指纹模块"** → ①TX和RX接反了，对调；②检查 VCC 和 V_Touch 是不是都在 3V3（V_Touch 最容易漏）；③核对商家带线的线序与丝印；④默认波特率57600
3. **舵机转但门不开** → 线太松就调紧；或把 `openAngle = 110` 改成 `120`、`130`，一次改一点
4. **指纹偶尔认不出** → 同一根手指多录几个编号；擦传感器
5. **板子上印着"WROVER"字样**（不是WROOM）→ D16/D17 被 PSRAM 占用（官方确认），把代码里 `fp(Serial1, 16, 17)` 改成 `fp(Serial1, 26, 27)`，接线改为 模块TX→D26、RX→D27，然后拍照找我核对
