# 指纹门锁·零基础操作手册（完全新手版）

> 写给从来没碰过开发板的人。全程用大白话，每个步骤都告诉你：**做什么 → 会看到什么 → 不对怎么办**。

## 0. 先认识零件（每个都有大白话解释）

| 零件 | 长什么样 | 大白话 |
|---|---|---|
| ESP32 开发板 | 一块小电路板，有 USB 口 | 这台设备的大脑，相当于一台迷你电脑 |
| 指纹模块 HLK-ZW111 | 圆形小模块，上面有块圆玻璃 | 认手指的传感器，按上去能认出你 |
| SG90 舵机 | 小方块电机，带一个能转的塑料盘 | 会转到指定角度的小马达，用来拉门锁 |
| 杜邦线 | 一束彩色细线，两头有插针 | 电线，把零件互相连起来 |
| Type-C 数据线 | 手机那种线 | 给板子供电 + 把程序传进板子。**注意：有些线只能充电不能传数据** |
| 圆盘臂+螺丝 | 舵机包装里的塑料片和螺丝 | 装在舵机上，用来绑绳子拉锁 |

**先背 3 个词（遇到不认识回来查）：**

- **引脚**：板子上的小孔，像插线板的孔。板子边上的白色小字就是引脚名字。
- **上传**：把电脑上写好的程序"拷"进开发板。
- **串口监视器**：IDE 里的小窗口，能看到开发板"说话"（显示文字）。

## 2. 接线（最重要，照做）

两条铁律：

1. **接线的时候，板子绝对不要插电。**
2. **插完，先对照下面的检查清单，再通电。**

### 先接舵机（3 根线，看颜色）

舵机三根线的颜色是固定的：

1. **棕色或黑色**线 → 插板子上写着 **GND** 的孔
2. **红色**线 → 插板子上写着 **5V** 的孔（有的板子写 VIN）
3. **橙色或黄色**线 → 插写着 **D13** 的孔

### 再接指纹模块（6 根线，看丝印小字）

指纹模块自带的连接线每根对应一个引脚名（以丝印为准，不同商家的线颜色不一样）：

| 引脚名 | 插到板子哪里 | 备注 |
|---|---|---|
| V_Touch | **3V3** | 容易漏！必须插 |
| VCC | **3V3** | 只吃 3.3V |
| GND | GND | |
| TX | D16 | 交叉接 |
| RX | D17 | 交叉接 |
| TOUCH_OUT | D4 | 不接也行 |

> **"只有一个 3V3 孔，怎么插两根线？"**
> 一个针脚是"通电的公共点"，不是只能插一根线的插座，两根线叠着插是正常做法（并联，不会烧）。先把 VCC 那根插到底，再把 V_Touch 那根顺着针头剩下的部分插上去压紧。如果板子另一侧还有第二个标着 3V3 的孔，也可以用两个孔（电压一样）。实在插不稳，就拍板子照片发我，或买一根"一分二杜邦线"（一两块钱）。

**上电前检查清单（每项打勾）：**

- [ ] 指纹模块的 VCC 和 V_Touch **都**插在 3V3，没有一根插到 5V
- [ ] 舵机红线在 5V，没有插到 3V3
- [ ] 模块 TX 对板子 D16、RX 对 D17（交叉）
- [ ] 所有 GND 都接上了

### 通电自检

用 USB 线把板子插到充电头/充电宝：

- 看到板子蓝灯亮 → 正常
- 手指摸指纹模块玻璃面，灯有反应 → 正常
- 摸舵机有轻微"嗡嗡"震动感 → 正常（它只是待机）

## 3. 打开 Arduino IDE（已经装好了）

1. 双击桌面上 **Arduino IDE** 图标
2. 第一次打开可能要等一会儿，出现英文提示就点 OK 或关掉，**不影响使用**
3. 认识界面：最上面一排按钮，**→ 箭头 = 上传**（把程序拷进板子），**放大镜 = 串口监视器**（看板子说话）

## 4. 插板子、选板子、选端口

1. 用数据线把 ESP32 插到电脑 USB 口，电脑"叮咚"一声正常
2. 点菜单 **工具 → 开发板** → 找到 **esp32** 分类 → 选 **ESP32 Dev Module**
3. 点菜单 **工具 → 端口** → 选带 **COM** 的选项（比如 COM3）
   - 不知道怎么选：先记下插线前的列表，插上后**多出来的那个**就是你的板子
   - 端口列表是空的：这根 USB 线只能充电不能传数据，**换一根线**

## 5. 录指纹

1. 打开程序：**文件 → 示例 → HLK_fingerprint → enroll**
   （或者 文件 → 打开，选我们做好的 [enroll_fingerprint.ino](enroll_fingerprint.ino)）
2. 点**上传**（箭头按钮）→ 第一次要等几分钟，进度条走完显示"上传成功"= 好了
3. 点**串口监视器**（放大镜）→ 右下角波特率选 **115200**
4. 看到"指纹模块连接成功！" = 硬件全通了。**没看到**就先看第 9 节对照表第 2 条
5. 在顶部输入框打 `1` 回车
6. 按提示做：**放手指**（按实，停 1~2 秒）→ **拿开** → **同一根手指再按一次** → 显示"录入成功！编号 1"
7. 同一根手指**再录一次编号 2**（这样它更认你）
8. 想给室友用：输入 3、4、5……每人一根手指一个编号

## 6. 上传开门程序（桌上测试）

1. 文件 → 打开，选 [fingerprint_doorlock.ino](fingerprint_doorlock.ino)
2. 上传
3. 验收标准：**手指按模块 → 蓝灯亮 + 舵机转到 110° → 2 秒后转回来**
   - 舵机不动：看对照表第 3 条
   - 舵机转但角度不够：改代码里 `openAngle = 110` 成 `120`，再上传
4. 全部正常后：拔掉电脑，插充电头再按一次，确认还正常 → **电子部分完成，可以装门了**

## 7. 装到门上（断电操作）

原理一句话：舵机转 → 绳子拉锁钮 → 开锁；舵机松 → 橡皮筋把锁钮拉回 → 上锁。

1. 先用手拨门锁的锁钮，看：往哪边转是开锁、要转多少
2. 3M 双面胶把舵机粘在锁钮旁边（绳子拉的方向那一侧，距离 5~10cm），**用力按住 1 分钟**，再用扎带加固
3. 舵机装上圆盘臂（用最外面的孔，拉力最大）
4. 绳子一头绑圆盘臂外孔，一头绑锁钮（锁钮有孔就穿过去打结；没孔就用扎带勒一圈再绑绳子）
5. 调绳长：舵机在 0°（待机）时，绳子**刚好绷直、但拉不动锁钮**
6. 锁钮另一侧粘个小挂钩，挂橡皮筋，方向朝"上锁位"，力度调到"能自己拉回去、手指拨开不费劲"
7. 指纹模块用 3M 胶贴在门板顺手的位置（圆玻璃朝外），线沿门边固定好
8. 测试：连按 10 次，每次都全开全回；拔电后手拨锁钮要轻松

## 8. 日常使用

- 供电：1A 以上充电头，24 小时插着。充电宝只临时用
- 认不出手指：擦干净玻璃面；同一根手指多录几个编号
- **逃生底线：任何时候拔掉电，手都要能轻松拨开锁钮。做不到就换更松的橡皮筋。**
- 装之前问宿管/家长，确认不影响消防逃生

## 9. 卡住对照表

| 症状 | 原因（按顺序查） | 怎么办 |
|---|---|---|
| 上传失败 | ①数据线不能传数据 ②板子卡住了 | ①换线 ②按住板上 BOOT 键再点上传 |
| 显示"没连上指纹模块" | ①TX/RX 接反 ②V_Touch 漏接 ③线序不对 ④波特率错 | ①对调 TX/RX ②确认 V_Touch 和 VCC 都在 3V3 ③对丝印 ④波特率选 57600 |
| 舵机转但门不开 | 绳太松 / 角度不够 | 绳调紧；openAngle 110→120→130 |
| 指纹偶尔认不出 | 传感器脏 / 录得太少 | 擦玻璃；同指多录几个编号 |
| 板子上印着 WROVER | D16/D17 被占用 | 代码里 `fp(Serial1, 16, 17)` 改成 `fp(Serial1, 26, 27)`，接线改 TX→D26、RX→D27，拍照给我 |
